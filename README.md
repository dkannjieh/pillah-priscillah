# Pillah Priscilah Custom Cake Studio
Premium HTML/CSS/JS website. 

## Deployment (Vercel)
1. Drag and drop this folder to your Vercel dashboard.
2. It will deploy automatically. No build step required.

## Structure
- index.html: Main layout and structure
- style.css: Styles (No frameworks needed)
- script.js: Multi-step form engine and interactive logic
